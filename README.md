# ts-practice

TypeScript と React の練習用リポジトリ。数当てゲームのロジックを TypeScript で書き、React で画面を作る。

## 使っている技術

- TypeScript
- React
- Vite

## 動かし方

```bash
npm install
npm run dev
```

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動する |
| `npm run build` | 型チェックをしてからビルドする |
| `npm run lint` | ESLint でチェックする |
